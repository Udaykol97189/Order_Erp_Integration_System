# Order_Erp_Integration_System

# Integrated Business Sales, Order & ERP Integration Platform

## Project 1

A production-oriented business order management and ERP integration project built to demonstrate practical skills in:

* Python
* FastAPI
* PostgreSQL
* Odoo
* REST APIs
* Docker
* Git
* Automated Testing

## Business Objective

The system is designed around a realistic B2B company that needs to manage:

* Customers
* Products
* Quotations
* Sales Orders
* Inventory
* Deliveries
* Invoices
* External system integrations

## Planned Architecture

```text
External Client / System
          |
          v
       FastAPI
          |
          v
        Odoo
          |
          v
      PostgreSQL
```
